# AquaGuard AI Project Proposal

AquaGuard AI is a decision-support prototype for SDG 6 that flags anomalous campus water-consumption patterns from aggregate meter-like time series and provides evidence-grounded operational recommendations.

## Scope
- Synthetic hourly data generation for six buildings over 90 days.
- Expected-consumption baseline and anomaly detection comparison.
- Explainable risk scoring and retrieval-grounded recommendations.
- Streamlit dashboard for campus facility stakeholders.

## Explicit Non-Claims
- Not guaranteed physical leak detection.
- No autonomous shutoff logic.
- Human verification required before maintenance actions.

## Synthetic Data Disclosure
This dataset is synthetic and is used for development, demonstration, and evaluation. It does not represent actual campus utility records.
